COLLEGE EVENT REGISTRATION SYSTEM

How to run:
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Double-click index.html, or use the Live Server extension.
4. The website opens in your browser.

Features:
- Register Student
- Display Registrations
- Search Student by ID
- Cancel Registration
- Count Total Registrations
- Browser local storage

Note:
This is the ready-made browser interface for the same College Event Registration System project.
The original C linked-list program is a separate console implementation.
